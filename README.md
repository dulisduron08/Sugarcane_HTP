# Sugarcane_HTP
The dataset includes plot-level multispectral-derived vegetation indices and corresponding ground-truth measurements for each plot. Ground truth is cane yield, stalk number, sample cane yield and yield monitor cane yield. 


Description of the data and file structure



This dataset was collected to evaluate UAV and yield monitor sensor high-throughput phenotyping for cane yield in a sugarcane breeding program. This dataset includes ground-based plot-level measurements of cane yield mesaured with a weigh wagon, cane yield mesaured as a sample, cane yield measured with a yield monitor sysyem and stalk number along with metrics derived from UAV-based multispectral imagery.
